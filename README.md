# RIARS-Renou-Integral-Automation-Radio-Solution-
RIARS - Software open source de automatización de emisoras de radio. Motor de audio profesional en Rust con crossfade, mezcla y streaming Icecast. API REST + MCP para control por agentes IA. Multiplataforma: Linux, Windows, macOS, Raspberry Pi (headless) y Android. Licencia MIT.
