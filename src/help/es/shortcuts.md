# Atajos de teclado

| Teclas | Acción |
|---|---|
| **F1** | Abrir el manual |
| **F5** | Reproducir |
| **F6** | Pausa |
| **F7** | Detener |
| **F8** | Siguiente pista |
| **Ctrl+O** | Abrir una playlist guardada |
| **Ctrl+S** | Guardar la lista de reproducción |
| **Ctrl+L** | Buscar en la biblioteca |
| **Ctrl+Mayús+A** | Añadir una carpeta a la biblioteca |
| **Ctrl+E** | Activar o desactivar la automatización |
| **Ctrl+1** … **Ctrl+7** | Pestañas: Lista de reproducción, Programación, Relojes, Parrilla, Categorías, Publicidad, Registro |
| **Ctrl+Q** | Salir |
| **F10** o **Alt** | Ir a la barra de menús; luego, las flechas, **Intro** y **Esc** |

Las teclas de función (**F5**–**F8**) funcionan aunque estés escribiendo en un campo de texto. En macOS, usa **Cmd** en lugar de **Ctrl**.

## En el manual

- Escribe para buscar. Con las **flechas** recorres los resultados e **Intro** abre el elegido.
- **Esc** cierra el manual.
