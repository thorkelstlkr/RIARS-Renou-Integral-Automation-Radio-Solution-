# Glosario

| Término | Significado |
|---|---|
| **Backtiming** | Elegir la duración de las canciones para llegar a tiempo a una hora fija. |
| **Bloque de anuncios** | Hueco del reloj donde entran las cuñas. |
| **Bumper** | Pieza corta de entrada o salida de un programa o bloque. |
| **Cama musical** | Música de fondo para hablar encima. |
| **Categoría** | Grupo de pistas del que tira la automatización. Consulta [Categorías](topic:categories). |
| **Crossfade** | Fundido entre el final de una pista y el principio de la siguiente. |
| **Cuña** | Anuncio publicitario grabado (*spot*). |
| **Franja** (*daypart*) | Parte del día con una programación propia: mañana, tarde, noche… |
| **Hora fija** (*ancla*) | Momento del reloj en que debe empezar un hueco, como los anuncios a las :15. Puede ser blanda o dura. |
| **Hueco** (*slot*) | Cada elemento de un reloj: una categoría, imagen, un bloque de anuncios… |
| **Imagen de emisora** | Jingles, indicativos, sweepers y bumpers. Consulta [Imagen de emisora](topic:imaging). |
| **Indicativo** (*station ID*) | Pieza que identifica la emisora, normalmente en la hora en punto. |
| **Jingle** | Pieza musical corta con el nombre de la emisora. |
| **Parrilla** (*grid*) | Qué reloj suena cada hora de cada día. Consulta [Parrilla](topic:grid). |
| **Registro de emisiones** (*proof of play*) | Lo que sonó de verdad, con hora real. Consulta [Registro de emisiones](topic:proof-of-play). |
| **Reloj** (*clock*) | Plantilla de una hora de radio. Consulta [Relojes](topic:clocks). |
| **Rotación** | El orden en que se van turnando las pistas de una categoría. |
| **Separación** | El tiempo mínimo entre repeticiones de una canción, un artista o un álbum. |
| **Silencio en antena** (*dead air*) | Silencio no deseado en la emisión. |
| **Sweeper** | Pieza hablada, con efectos, entre dos canciones. |
