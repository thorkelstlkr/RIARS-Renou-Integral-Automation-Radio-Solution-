# Keyboard shortcuts

These shortcuts work in the desktop app.

| Keys | Action |
|---|---|
| **F1** | Open the manual |
| **F5** | Play |
| **F6** | Pause |
| **F7** | Stop |
| **F8** | Next track |
| **Ctrl+O** | Open a saved playlist |
| **Ctrl+S** | Save the playlist |
| **Ctrl+L** | Search the library |
| **Ctrl+Shift+A** | Add a folder to the library |
| **Ctrl+E** | Turn automation on or off |
| **Ctrl+1 … Ctrl+7** | Tabs: Playlist, Scheduling, Clocks, Grid, Categories, Advertising, Log |
| **Ctrl+Q** | Quit |

## Menus

The same actions are in the in-window menus:

- **File:** Add folder to library… · Open playlist… · Save playlist… · Export log (CSV)… · Quit
- **Edit:** Search the library · Clear the playlist
- **View:** the seven tabs · Language ▸
- **Playback:** Play · Pause · Stop · Next · Crossfade… · Silence detector…
- **Automation:** Automation on/off · Preview… · Clocks · Grid · Categories · Advertising · Station settings
- **Broadcast:** Streaming settings… · Start streaming · Stop streaming
- **Help:** Manual (F1) · Keyboard shortcuts · Web panel and server · About RIARS

> Tip: the transport keys are the fastest way to fix a wrong start during a live show. See [Playback](topic:playback) and [The main window](topic:main-window).
