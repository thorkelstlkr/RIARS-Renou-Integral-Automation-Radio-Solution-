# Glossary

| Term | Meaning |
|---|---|
| **Clock** | A format clock: the list of slots that makes up one period, usually an hour. See [Format clocks](topic:clocks). |
| **Daypart** | A block of the day when something is allowed or scheduled, for example advertising only from 07:00 to 10:00. |
| **Grid** | The dayparts grid: the rules that decide which clock or playlist plays in each hour of the week. See [The grid](topic:grid). |
| **Slot** | One entry in a clock: a category, imaging, an ad break, a playlist, a fixed track or a fill. |
| **Anchor** | A time inside a clock where a slot should start, such as `15:00` for an ad break. A **hard** anchor cuts in exactly; a **soft** anchor waits for the current song. |
| **Imaging** | Short station audio: jingles, sweepers, bumpers, station IDs and beds. |
| **Sweeper** | A short effect or voice piece used between songs, often on a style change. |
| **Bumper** | A very short sting or ident used to separate items. |
| **Station ID** | The station's audio logo, usually played at the top of the hour. |
| **Spot** | A commercial, also called a cuña. |
| **Proof of play** | The log of what really aired, with real times and reasons. See [Proof of play](topic:proof-of-play). |
| **Rotation** | The policy that decides how often each track in a category is picked. A higher weight means more plays. |
| **Separation** | The minimum time or number of items between two plays of the same song, artist or album, or between the same imaging item. |
| **Backtiming** | Choosing the last songs of a block by length so the next fixed point is reached on time. |
| **Crossfade** | Fading one item out while the next fades in. See [Crossfade](topic:crossfade). |

> Tip: the manual uses these words in the same sense as RIARS's screens, so a term in a clock or campaign field means the same thing here.
