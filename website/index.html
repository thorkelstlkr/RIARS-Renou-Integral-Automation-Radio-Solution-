La radio que tu asistente de IA sabe programar

RIARS (Renou Integral Automation Radio Solution) automatiza una emisora entera: biblioteca, parrilla, directo y streaming. Y lo expone todo como herramientas MCP, para que Claude u otro asistente lo maneje con llamadas estructuradas, no con clics.

Arquitectura MCP

Una emisora que se maneja hablando

El Model Context Protocol (MCP) es el estándar abierto con el que los asistentes de IA usan herramientas externas. RIARS trae un servidor MCP: arrancas riars-server --mcp-stdio, lo añades a Claude Desktop, Claude Code u otro cliente compatible, y el asistente ve 80 herramientas con sus parámetros descritos y validados.

  • Llamadas estructuradas. Cada herramienta tiene un esquema JSON; si un dato no cuadra, RIARS lo rechaza con un error claro en vez de adivinar.
  • Lo mismo que hace un operador. Reproducir, programar, abrir el micro, lanzar jingles y revisar qué ha sonado.
  • Seguro por diseño. Abrir el micrófono a distancia solo funciona si lo permites en sus ajustes; cerrarlo, siempre.

¿Prefieres HTTP? Hay API REST

Las mismas funciones están en http://servidor:3100/api/v1/…, con token Bearer, y un WebSocket en /ws/events avisa de cada cambio. Sirve para scripts, paneles propios o agentes que no hablan MCP.

curl -H "Authorization: Bearer MI_TOKEN" \
  http://localhost:3100/api/v1/status
curl -X POST -H "Authorization: Bearer MI_TOKEN" \
  http://localhost:3100/api/v1/player/play

Funciones

Todo lo que necesita una emisora

Automatización de largo plazo

Relojes de formato para cada hora, una parrilla semanal con excepciones por fecha y categorías con reglas. El generador llena la lista durante días o semanas sin operador.

Directo con micrófono

Abre el micro y la música baja sola; al cerrarlo, vuelve. Modos automático, asistido y manual para cada tipo de programa.

Banco de sonidos

Ocho páginas de 24 botones para jingles, efectos y cortinas. Se lanzan con un clic, con el teclado o desde la IA.

Intros y outros

RIARS analiza cada pista y lanza el identificativo sobre la intro instrumental, terminando antes de la voz. Nunca pisa al cantante.

Normalización

Sonoridad medida según EBU R128: cada pista suena al mismo nivel percibido, −16 LUFS por defecto, lo habitual en radio por Internet.

Streaming a Icecast

Emite en MP3 a tu servidor Icecast. El servidor sin pantalla puede emitir incluso sin tarjeta de sonido.

Registro de emisiones

Anota lo que ha sonado de verdad y a qué hora, con informes de emisión por campaña para tus anunciantes.

Carpetas de la biblioteca

Añade tus carpetas de música: RIARS las escanea, las vuelve a revisar al arrancar y te las muestra en árbol.

Crossfade y silencio

Transiciones suaves entre pistas y un detector que salta el elemento si la salida se queda en silencio demasiado tiempo.

Descargar

Descárgalo y compílalo

Por ahora RIARS se instala desde el código fuente. Necesitas Rust 1.77 o superior y, para la app de escritorio, Node.js 20 o superior y las dependencias de Tauri.

  1. Clona el repositorio

    git clone https://github.com/thorkelstlkr/RIARS-Renou-Integral-Automation-Radio-Solution-.git riars
cd riars

  2. App de escritorio (Windows, macOS, Linux)

    Pruébala con npm run tauri dev o genera el instalador:

    npm install
npm run tauri build

  3. Servidor sin pantalla (Linux, Raspberry Pi)

    cargo build -p riars-server --release
./target/release/riars-server --port 3100 --api-token MI_TOKEN

    Para una Raspberry Pi desde un PC x86_64:

    rustup target add aarch64-unknown-linux-gnu
cargo build -p riars-server --release --target aarch64-unknown-linux-gnu

  4. Conecta tu asistente de IA

    En Claude Code:

    claude mcp add riars -- /ruta/a/riars-server --mcp-stdio

    En Claude Desktop u otro cliente MCP, añade esto a su configuración (en Claude Desktop, claude_desktop_config.json):

    {
  "mcpServers": {
    "riars": {
      "command": "/ruta/a/riars-server",
      "args": ["--mcp-stdio"]
    }
  }
}
