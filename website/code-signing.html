Code signing policy

Política de firma de código

Firma de código gratuita proporcionada por SignPath.io, con certificado de SignPath Foundation.

Estado: RIARS ha solicitado entrar en el programa de SignPath Foundation. Hasta que lo aprueben, los instaladores siguen sin firmar.

Qué se firma

  • El instalador de Windows (RIARS-windows-x64-setup.exe) y los programas que instala.
  • Solo se firma lo que se compila desde el repositorio público con GitHub Actions, en máquinas alojadas por GitHub. Nada se compila ni se firma en un ordenador personal.
  • Cada firma la aprueba a mano una persona del equipo, versión por versión.
  • No se firman bibliotecas de terceros con este certificado.

Equipo

  • Autores y revisores (pueden cambiar el código y revisan las contribuciones externas): thorkelstlkr
  • Aprobadores (aprueban cada firma): thorkelstlkr

Todos usan verificación en dos pasos en GitHub y en SignPath.

Privacidad

Este programa no transfiere ninguna información a otros sistemas de red salvo que lo pida expresamente el usuario o la persona que lo instala o lo maneja. Los detalles están en la política de privacidad.

Desinstalar

En Windows, desde Configuración ▸ Aplicaciones ▸ RIARS ▸ Desinstalar. La biblioteca de música y los archivos de audio no se borran.
