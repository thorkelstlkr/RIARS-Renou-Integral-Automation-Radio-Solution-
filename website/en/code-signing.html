Code signing policy

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: RIARS has applied to the SignPath Foundation program. Until it is approved, the installers remain unsigned.

What is signed

  • The Windows installer (RIARS-windows-x64-setup.exe) and the programs it installs.
  • Only what is built from the public repository by GitHub Actions on GitHub-hosted runners is signed. Nothing is built or signed on a personal computer.
  • A team member approves every signing by hand, release by release.
  • Third-party libraries are not signed with this certificate.

Team

  • Committers and reviewers (can change the code and review outside contributions): thorkelstlkr
  • Approvers (approve every signing): thorkelstlkr

All of them use two-factor authentication on GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. See the privacy policy for details.

Uninstalling

On Windows, go to Settings ▸ Apps ▸ RIARS ▸ Uninstall. Your music library and audio files are not deleted.
