Radio automation your AI assistant can run

RIARS (Renou Integral Automation Radio Solution) runs a whole station: library, programming grid, live shows and streaming. It exposes all of it as MCP tools, so Claude or another assistant drives it with structured calls instead of clicks.

MCP architecture

A station you run by talking to it

The Model Context Protocol (MCP) is the open standard AI assistants use to work with outside tools. RIARS ships an MCP server: start riars-server --mcp-stdio, add it to Claude Desktop, Claude Code or another compatible client, and the assistant sees 80 tools with described, validated parameters.

  • Structured calls. Every tool has a JSON schema; if a value is wrong, RIARS rejects it with a clear error instead of guessing.
  • Everything an operator does. Play, schedule, open the mic, fire jingles and check what aired.
  • Safe by design. Opening the microphone remotely only works if its settings allow it; closing it always does.

Prefer HTTP? There's a REST API

The same features are at http://server:3100/api/v1/…, with a Bearer token, and a WebSocket at /ws/events reports every change. Use it for scripts, your own dashboards or agents that don't speak MCP.

curl -H "Authorization: Bearer MY_TOKEN" \
  http://localhost:3100/api/v1/status
curl -X POST -H "Authorization: Bearer MY_TOKEN" \
  http://localhost:3100/api/v1/player/play

Features

Everything a station needs

Long-term automation

Format clocks for each hour, a weekly grid with date exceptions and rule-based categories. The generator fills the playlist for days or weeks with nobody at the desk.

Live microphone

Open the mic and the music dips by itself; close it and it comes back. Automatic, assisted and manual modes for every kind of show.

Sound bank

Eight pages of 24 buttons for jingles, effects and beds. Fire them with a click, the keyboard or your AI assistant.

Intros and outros

RIARS analyses each track and plays the station ID over the instrumental intro, ending before the vocals. It never talks over the singer.

Loudness normalisation

Loudness measured to EBU R128: every track plays at the same perceived level, −16 LUFS by default, usual for Internet radio.

Icecast streaming

Streams MP3 to your Icecast server. The headless server can stream even without a sound card.

Proof-of-play log

Records what really aired and when, with delivery reports per campaign for your advertisers.

Library folders

Add your music folders: RIARS scans them, checks them again at startup and shows them as a tree.

Crossfade and dead air

Smooth transitions between tracks, and a detector that skips the item if the output stays silent for too long.

Or build it from source

You need Rust 1.77 or later and, for the desktop app, Node.js 20 or later and the Tauri prerequisites.

  1. Clone the repository

    git clone https://github.com/thorkelstlkr/RIARS-Renou-Integral-Automation-Radio-Solution-.git riars
cd riars

  2. Desktop app (Windows, macOS, Linux)

    Try it with npm run tauri dev or build the installer:

    npm install
npm run tauri build

  3. Headless server (Linux, Raspberry Pi)

    cargo build -p riars-server --release
./target/release/riars-server --port 3100 --api-token MY_TOKEN

    For a Raspberry Pi, from an x86_64 PC:

    rustup target add aarch64-unknown-linux-gnu
cargo build -p riars-server --release --target aarch64-unknown-linux-gnu

  4. Connect your AI assistant

    In Claude Code:

    claude mcp add riars -- /path/to/riars-server --mcp-stdio

    In Claude Desktop or another MCP client, add this to its configuration (in Claude Desktop, claude_desktop_config.json):

    {
  "mcpServers": {
    "riars": {
      "command": "/path/to/riars-server",
      "args": ["--mcp-stdio"]
    }
  }
}
