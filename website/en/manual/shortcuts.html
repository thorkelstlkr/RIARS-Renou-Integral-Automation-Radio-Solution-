Keyboard shortcuts

These shortcuts work in the desktop app.

KeysAction
F1Open the manual
F5Play
F6Pause
F7Stop
F8Next track
Ctrl+OOpen a saved playlist
Ctrl+SSave the playlist
Ctrl+LSearch the library
Ctrl+Shift+AAdd a folder to the library
Ctrl+ETurn automation on or off
Ctrl+1 … Ctrl+8Tabs: Playlist, Scheduling, Clocks, Grid, Categories, Advertising, Log, Live
Ctrl+PPre-listen to the track selected in the library
Ctrl+QQuit

Menus

The same actions are in the in-window menus:

  • File: Add folder to library… · Open playlist… · Save playlist… · Export log (CSV)… · Quit
  • Edit: Search the library · Clear the playlist
  • View: the seven tabs · Language ▸
  • Playback: Play · Pause · Stop · Next · Crossfade… · Silence detector… · Normalisation… · Sound cards…
  • Automation: Automation on/off · Preview… · Clocks · Grid · Categories · Advertising · Station settings
  • Broadcast: Streaming settings… · Start streaming · Stop streaming
  • Help: Manual (F1) · Keyboard shortcuts · Web panel and server · About RIARS

Tip: the transport keys are the fastest way to fix a wrong start during a live show. See Playback and The main window.
